# Security Policy

Kargus is an authentication broker and RBAC operator; security reports are taken seriously.

## Reporting a vulnerability

**Do not open a public issue for security vulnerabilities.**

Report privately via [GitHub Security Advisories](https://github.com/kube-argus/kargus/security/advisories/new)
or email **oss@kargus.io**.

Please include:

- A description of the issue and its impact
- Steps to reproduce (affected component: operator, broker, proxy, or chart)
- Any suggested fix, if you have one

You will get an acknowledgement within 7 days. Fixes for confirmed vulnerabilities
are released as soon as practical, and reporters are credited unless they prefer otherwise.

## Supported versions

Only the latest release receives security fixes.
